# Система распознавания поведения сотрудников на рабочем месте

Прототип программно-аппаратного комплекса видеоаналитики для автоматического контроля и классификации действий сотрудников в режиме реального времени. Проект разработан в рамках выпускной квалификационной работы (направление подготовки 02.03.03).

## Ключевой функционал
* **Детекция и трекинг:** Локализация сотрудников в кадре с использованием предобученных весов.
* **Классификация действий:** Распознавание паттернов поведения (*сидит, стоит/ходит, разговаривают (два и более сотрудника в кадре), упал).
* **Медиа-пайплайн:** Декодирование и обработка видеопотока.
* **Веб-интерфейс:** Панель мониторинга для оператора с выводом обработанного видео (Bounding Boxes + метки классов).

## Технологический стек
* **AI / Computer Vision:** Python, YOLOv8 (Ultralytics), OpenCV
* **Data Processing & Media:** ffmpeg, CVAT (разметка исходного датасета)
* **Backend:** Flask
* **Frontend:** HTML5, CSS3, JavaScript

---

## Архитектура решения

Проект реализует двухэтапный конвейер (Pipeline) обработки данных:
1. Поток с камеры/видеофайла перехватывается через **OpenCV / ffmpeg**.
2. Кадры передаются в модель **YOLOv8**, где происходит детекция человека и классификация его текущего состояния на основе обученного кастомного датасета.
3. Результаты детекции отрисовываются на кадре и стримятся в веб-интерфейс, развернутый на **Flask**.

## Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/aka56kg/employee-behaviour-detection
cd employee-behavior-detection
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение `venv`:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate  # Для Windows

pip install -r requirements.txt
```

### 3. Запуск приложения
```bash
python app.py
```
После запуска веб-панель будет доступна по адресу: `http://127.0.0.1`

* **Инструмент разметки:** CVAT (Cloud / Self-hosted)
